# Lanz Lionel Miguel Portfolio

Personal portfolio website for Lanz Lionel Miguel, a web developer and virtual assistant based in Davao City, Philippines.

## Live website

[Visit Site](lnzmiglldev.vercel.app)

## About the project

This portfolio introduces me, summarizes my experience and current skills, and presents selected web projects. It is intentionally built with a simple structure so I can continue improving it as I learn.

## Features

- Responsive desktop and mobile layout
- About, experience, skills, projects, and gallery sections
- Live project links and a link to this source repository
- Keyboard-accessible gallery controls and image viewer
- Reduced-motion support
- GitHub contribution activity with a profile fallback
- Search and social-sharing metadata

## Built with

- Semantic HTML5
- Responsive CSS3
- Vanilla JavaScript for optional gallery and contribution enhancements
- Font Awesome icons
- Google Fonts

JavaScript is part of my current learning journey. The main portfolio content remains available even if optional JavaScript features or external services fail.

## Run locally

No build tools or package installation are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/LnzMigll14/PortfolioWebpage_Ver2.git
   cd PortfolioWebpage_Ver2
   ```

2. Open `index.html` directly, or start a simple local server:

   ```bash
   python -m http.server 4173
   ```

3. Visit `http://localhost:4173` in your browser.
